## 技术实现细节

### 使用的技术栈
- Vue 3 Composition API
- Vite 构建工具
- Axios HTTP客户端
- Bootstrap样式框架

### 主要组件
1. **PDFLoaderView.vue** - 主要的PDF上传组件
2. **FilePreview.vue** - 文件预览组件
3. **api.js** - API服务层

### 核心功能流程
1. 用户通过拖拽或点击选择PDF文件
2. 文件被添加到上传队列并显示在列表中
3. 用户点击"开始处理"按钮
4. 系统逐个上传文件到后端
5. 显示实时上传进度
6. 处理完成后显示结果统计

1. 打开PDF上传页面
2. 拖拽或选择PDF文件

6. 查看处理结果提示

### 注意事项
- 确保后端服务正常运行
- 网络连接稳定
- 文件大小不超过50MB
- 仅支持PDF格式文件
